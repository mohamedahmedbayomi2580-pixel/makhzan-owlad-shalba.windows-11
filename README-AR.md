# مشروع Windows — مخزن ولاد شلبه

هذه حزمة مستقلة لنسخة Windows، ولا تستبدل Workflow الخاص ببناء APK.

## الملفات
- `desktop/app/index.html`: نسخة HTML المرفقة في المحادثة.
- `desktop/main.cjs`: تشغيل نافذة Electron.
- `desktop/preload.cjs`: تخزين متوافق مع localStorage، لكن البيانات تُكتب في ملف محلي داخل مجلد بيانات التطبيق بدل حصة localStorage الصغيرة.
- `desktop/package.json`: إعدادات بناء مُثبّت Windows.
- `.github/workflows/build-windows-exe.yml`: بناء EXE تلقائيًا عبر GitHub Actions.

## الرفع إلى المستودع الجديد
1. فك ضغط هذه الحزمة.
2. ارفع محتويات المجلد إلى جذر مستودع GitHub الجديد `makhzan-windows`، مع الحفاظ على المجلدات كما هي.
3. اعمل Commit للملفات على `main`.
4. افتح Actions ثم `Build Windows EXE` وانتظر انتهاء البناء.
5. من صفحة التشغيل الناجح نزّل Artifact باسم `makhzan-windows-installer`؛ داخله ملف التثبيت `.exe`.

## التخزين
في نسخة الكمبيوتر، قاعدة البيانات تُخزن محليًا في ملف `database.json` ضمن مجلد بيانات التطبيق، وليس في localStorage محدود المتصفح. هذا يزيل اعتماد البيانات على حصة localStorage الصغيرة، لكنه لا يجعل التخزين غير محدود؛ يظل خاضعًا لمساحة القرص. احتفظ بنسخ احتياطية دورية.

## تنبيه
هذه الحزمة جُهّزت اعتمادًا على ملف HTML المتاح في المحادثة، ولم يتم اختبارها على جهاز Windows فعلي داخل هذه البيئة. اختبر وظائف البرنامج والنسخ الاحتياطي بعد أول بناء. بيانات الكمبيوتر مستقلة عن بيانات نسخة Android ولن تنتقل تلقائيًا بينهما.
